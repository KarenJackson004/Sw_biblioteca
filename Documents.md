## Introducción
Esta documento se desarrolla a lo largo de la asignatura con el fin de crear un programa para la gestión administrativa de una biblioteca de una institución educativa, se requiere que el programa sea totalmente funcional con sus distintos modulos y requemientos en cada gestión, de esta forma el programa automatizaria los procesos y la administración de los libros, prestamos, usuarios, etc.

## Objetivos
- Aplicar principios de POO
- Diseñar una GUI facil de manipular para el usuario y ademas atractiva
- Implementar operaciones CRUD
- Se hace uso de SQL Server para el desarrollo de la base de datos
- Crear codigo totalmente funcional respondiendo a requerimiento del usuario y a la conexión con la base de datos
- Validar información ingresada por el usuario enviando mesajes de excepciones
- Utilizar Git y GitHub como controlador de versiones
- Desarrollar una documentación tecnica del proyecto
